# ⚡ Energia por Assinatura (GD) vs. Mercado Livre — Comparação com Preços Reais

> Preços reais de julho/2026. Fontes: CCEE, ANEEL, Abraceel.

## 1. PREÇOS REAIS PRATICADOS HOJE (Julho 2026)

### Quanto custa a energia da CONCESSIONÁRIA (o monopólio)

```
Tarifa média FINAL (energia + rede + impostos) que o cliente paga:

  Enel SP:   R$ 0,85 a R$ 1,00/kWh  (reajuste de 15,46% em 2026)
  Enel RJ:   R$ 0,90 a R$ 1,10/kWh  (reajuste de 15,46% em 2026)
  CPFL:      R$ 0,80 a R$ 0,95/kWh  (reajuste de 9,25% em 2026)
  Cemig:     R$ 0,75 a R$ 0,90/kWh  (reajuste de 6,50% em 2026)

  MÉDIA NACIONAL COMERCIAL: ~R$ 0,85/kWh (R$ 850/MWh)

  Essa tarifa TEM TUDO embutido:
  ├── Energia (a commodity): ~50-55% da conta
  ├── Distribuição (fios e postes): ~25-30% da conta
  ├── Encargos e impostos: ~15-25% da conta
  └── Bandeira tarifária (quando ativa): variável
```

### Quanto custa a energia no MERCADO LIVRE (atacado)

```
Preço da energia no mercado livre (SÓ A COMMODITY, sem rede):

  PLD médio (curto prazo, jul/2026): R$ 195/MWh = R$ 0,195/kWh
  Contrato longo prazo (24-36 meses): R$ 233/MWh = R$ 0,233/kWh
  Contrato trimestral (curto prazo):  R$ 317/MWh = R$ 0,317/kWh

  PREÇO QUE A COMERCIALIZADORA VENDE PRO CLIENTE FINAL:
  R$ 280 a R$ 400/MWh = R$ 0,28 a R$ 0,40/kWh
  (ela coloca a margem dela em cima do preço de compra)
```

### Quanto custa a Energia por Assinatura (GD)

```
O desconto que as usinas de GD oferecem ao consumidor:

  Desconto sobre a conta da concessionária: 10% a 20%
  (em 2026, por causa da "taxação do sol" Lei 14.300,
   o desconto caiu. Antes era 15-25%, agora é 10-20%)

  O cliente paga para a usina: 80-90% do valor do crédito
  O cliente economiza: 10-20% da parcela de energia

  EXEMPLO: Se a conta é R$ 500 e os créditos são R$ 300:
  → Cliente paga pra usina: R$ 240-270 (80-90% de R$ 300)
  → Desconto na conta Enel: R$ 300
  → Economia real: R$ 30-60/mês (10-20% dos R$ 300)
```

## 5. RESUMO BRUTAL

```
ENERGIA POR ASSINATURA (GD):
→ O cliente ganha DESCONTO na conta da Enel (créditos da usina solar)
→ A Enel continua vendendo, mas a conta vem menor
→ É como um CUPOM DE DESCONTO na conta de luz
→ Funciona pra TODO MUNDO

MERCADO LIVRE:
→ O cliente TROCA quem vende a energia (sai da Enel, vai pra Clarke)
→ A Enel continua ENTREGANDO (postes e fios), mas para de VENDER
→ É como TROCAR DE OPERADORA de celular
→ Funciona só pra EMPRESAS (por enquanto)

A DIFERENÇA FUNDAMENTAL:
┌──────────────────────────────────────────────────────┐
│                                                      │
│  GD = DESCONTO na mesma conta (o cupom)              │
│  ML = TROCA DE FORNECEDOR (muda de operadora)        │
│                                                      │
│  GD = A Esol ganha o SPREAD (diferença de preço)     │
│  ML = A Esol ganha COMISSÃO da comercializadora      │
│                                                      │
│  GD = Economia de 10-20%                             │
│  ML = Economia de 10-25%                             │
│                                                      │
│  GD = Pra todo mundo                                 │
│  ML = Pra empresas (2026) e casas (2028)             │
│                                                      │
│  GD = O dono paga um boleto da usina                 │
│  ML = O dono paga a fatura da comercializadora       │
│                                                      │
│  NÃO COMPETEM. SÃO COMPLEMENTARES.                  │
│  O app recomenda o melhor pra cada situação.         │
│                                                      │
└──────────────────────────────────────────────────────┘
```
